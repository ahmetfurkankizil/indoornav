# Demo Operator Guide — Vectura AI iOS MVP

Step-by-step procedure for running the Vectura AI investor demo.

## Before the Demo

### 1. Generate the Entrance Poster

The entrance poster is a **single printed artifact** that serves as both:
- The **QR code** scanned in step 1 (AVCaptureSession reads the embedded QR payload)
- The **AR reference image** detected in step 2 (ARKit matches the full poster image)

Generate it with the provided script:

```bash
cd /path/to/Vectura AI
./scripts/generate-entrance-poster.sh
```

This generates `sample/entrance-poster/entrance_poster.png` and copies it into the Xcode asset catalog automatically.

**If you regenerate the poster, you must rebuild the app** — the printed poster and the bundled AR reference image must be identical.

Print the poster at exactly **21 × 21 cm** on **matte white paper** with high contrast black ink.

### 2. Place the Poster

- Tape the poster to the entrance wall at **eye level (~1.2m from floor)**.
- The poster should face the user as they walk in.
- Ensure good lighting — no direct glare or deep shadow on the poster.
- The wall behind the poster should be flat.

### 3. Verify Readiness

Run the readiness check:

```bash
./scripts/check-demo-readiness.sh
```

All checks should pass. If any fail, fix before proceeding.

### 4. Build and Install

```bash
cd apps/iosApp
xcodebuild -project iosApp.xcodeproj -scheme iosApp -destination 'id=<DEVICE_ID>' -allowProvisioningUpdates
```

Or use Xcode: Open → Build → Run on device.

## During the Demo

### The Flow

1. **Home screen**: Tap "Scan QR Code"
2. **QR scan**: Point camera at the printed entrance poster
   - The app reads the QR code embedded in the poster
   - Validates it against the bundled package
   - If wrong QR: shows error with "Try Again"
3. **Entrance confirmed**: Shows "Starting from Entrance A"
   - Tap "Continue"
4. **Destination select**: Choose one of:
   - Mutfak (kitchen)
   - Salon (living room)
   - Yatak Odası (bedroom)
5. **Route preview**: Shows start/destination/distance
   - Tap "Start Navigation"
6. **AR alignment**: Shows "Point the camera at the entrance poster"
   - Hold phone facing the **same poster you just scanned**
   - ARKit detects the poster image and locks alignment
   - Once detected, arrows appear
7. **AR navigation**: Follow the blue arrows
   - Arrows slide forward as you walk
   - Passed arrows fade out
   - Turn indicators appear at junctions
8. **Arrival**: "You've arrived at [Room Name]"
   - Tap "Done" to return home

### Recommended Demo Order

1. **Mutfak** (shortest route, most straightforward)
2. **Salon** (medium length, shows a different branch)
3. **Yatak Odası** (longest route, shows the full corridor)

### Tips for a Smooth Demo

- **Hold phone steady** during poster scan. Quick, smooth motions.
- **Walk at normal pace.** The arrow lookahead adapts to your speed.
- **Stay in the corridor.** The route follows the center of hallways.
- **If tracking gets wobbly**, briefly point at a well-textured surface (wall art, furniture). ARKit will recover.
- **Don't cover the camera** with fingers when handing the phone over.

## Troubleshooting

### "No entrance poster detected" timeout (30s)

1. Check that you're pointing at the **same printed poster** you scanned in step 2 — it must be the poster generated by `generate-entrance-poster.sh`.
2. Check lighting — ensure the poster is well-lit, no glare.
3. Check print quality — poster must be crisp, not blurry.
4. Tap "Retry" to reset the scanner.
5. Ensure the poster was printed at **exactly 21 × 21 cm** — ARKit uses the physical size to match.

### "Detected image(s) but none matched" timeout

This means ARKit saw a reference image candidate but it didn't match the expected entrance poster. The printed poster may differ from the bundled asset. Regenerate and rebuild:

```bash
./scripts/generate-entrance-poster.sh
# Rebuild in Xcode
```

### "Poster Asset Missing" configuration error

The AR reference image is not in the app bundle. Run:
```bash
./scripts/generate-entrance-poster.sh
# Rebuild in Xcode
```

### QR scan shows error

- "QR code does not contain a valid Vectura AI payload" → Wrong QR code. Scan the correct entrance poster.
- "QR is for building X but this app has Y" → QR and app mismatch. Regenerate the poster.

### Arrows seem offset from the real path

- The poster may have been detected at an angle. Try:
  1. End navigation
  2. Return to home
  3. Rescan poster → rescan from directly in front

### Arrival doesn't trigger

- Walk closer to the door — within 1.5m of the door node position.
- The door node may need recalibration. See `docs/calibration-guide.md`.

## After the Demo

No cleanup required. The app resets to the home screen after each navigation session. The printed poster can be left in place for future demos.
