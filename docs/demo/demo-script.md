# Demo Script — 2–3 Minutes

> For investor presentations and team demos.

## Paths Available

| Path | What it uses | For |
|------|-------------|-----|
| **Live** | Real marker + walking | Device demos, on-site |
| **Scripted** | Simulate Scan + Advance | Remote, rehearsal, fallback |

---

## Setup (before meeting)
1. Install app on demo device (see [demo-setup.md](demo-setup.md))
2. For live path: print and mount marker (see [marker-guide.md](marker-guide.md))
3. Verify app shows "Vectura AI Demo Office"

---

## Script

### Act 1: "The Problem" (30 sec)
> *"Finding rooms in large buildings wastes 5–10 minutes. Vectura AI solves this with AR-guided indoor navigation."*

### Act 2: "Find Your Room" (30 sec)
1. Tap **Search** → type **"Conference"** → select **Conference Room**
> *"Natural language search across rooms, aliases, and categories."*

### Act 3: "Route Preview" (30 sec)
> *"Before AR, see complete route: 13m, step-by-step directions."*

1. Tap **Start AR**

### Act 4: "AR Navigation" (45 sec)

**Live path:**
1. Point camera at printed marker
2. Arrows appear in real space
3. Walk along route — progress updates automatically
4. Point out: remaining distance, tracking quality

**Scripted path:**
1. Tap **Simulate Scan** → arrows appear
2. Tap **Advance** 3–4 times
3. Point out progress bar filling

> *"3D arrows guide you. Progress tracks your movement in real time."*

### Act 5: "Arrival" (15 sec)
1. Progress ≥ 95% → arrival overlay
2. ✓ "You've arrived!" → tap **Done**

### Act 6: "History" (15 sec)
1. Open **History** → show completed visit

---

## Fallback Plan

| Problem | Solution |
|---------|----------|
| Marker won't scan | Use **Simulate Scan** |
| Progress stuck | Tap **Rescan** or switch to scripted |
| App crash | Restart app → demo package auto-loads |
| "3D quality?" | "Placeholder geometry for v1, production assets in v2" |
