# Demo Script — 2–3 Minutes

> For investor presentations and team demos. Use the **Demo** config profile.

## Setup (before the meeting)
1. Install app on demo device (see [demo-setup.md](demo-setup.md))
2. Ensure app launches and shows home screen
3. Verify "VecturAI Demo Office" is loaded (visible in app or debug panel)
4. If using a physical marker: place the printed marker at a visible location

---

## Script

### Act 1: "The Problem" (30 seconds)
> *"People waste 5-10 minutes finding rooms in large buildings. VecturAI solves this with AR-guided indoor navigation."*

**Show:** Home screen with building name

### Act 2: "Find Your Room" (30 seconds)
1. Tap **Search**
2. Type **"Conference"**
3. Select **Conference Room** from results

> *"Natural language search across all rooms, aliases, and categories."*

### Act 3: "Route Preview" (30 seconds)
**Show:** Route preview screen
> *"Before entering AR, users see the full route with distance, time estimate, and step-by-step directions."*

1. Point out: distance (~10m), estimated time, step count
2. Tap **Start AR**

### Act 4: "AR Navigation" (45 seconds)
1. If using real marker: point camera at printed marker  
   If demo mode: tap **Simulate Scan**
2. Show arrows appearing in AR view

> *"3D arrows guide you through the building. Turn markers, follow arrows, destination beacon."*

3. Tap **Advance** 3–4 times to show progress
4. Point out progress bar filling up

### Act 5: "Arrival" (15 seconds)
1. Progress reaches ~95% → arrival overlay appears
2. Show ✓ checkmark and "You've arrived!"
3. Tap **Done**

> *"The session is automatically saved to your visit history."*

### Act 6: "History" (15 seconds)
1. Navigate to **History**
2. Show completed visit with timestamp and destination

> *"Every visit is tracked. This data feeds future features like favorites and analytics."*

---

## Fallback Plan

| Problem | Solution |
|---------|----------|
| Marker not scanning | Use **Simulate Scan** button |
| App crashes on AR | Switch to route preview only, explain AR is optional |
| Slow package load | Demo package is embedded — restart app |
| Questions about 3D quality | "We're using placeholder geometry for v1, production assets in v2" |
