# ADR-014: Visual Polish Priorities for Investor MVP

**Status:** Accepted  
**Date:** 2026-03-08

## Decision

Polish existing surfaces rather than redesigning. Priority order: AR overlay clarity → session summary → history cards → route preview → home/search. Use consistent spacing, status colors, and typography hierarchy. No new design system.

## Consequences
- Incremental improvement, no regressions
- Happy path looks polished for investor demo
- Non-critical screens may still look basic
