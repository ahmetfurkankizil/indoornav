# File Dossier: AndroidManifest.xml

## Path
`apps/androidApp/src/main/AndroidManifest.xml`

## Type
Authored Config (Android Manifest)

## Role
Declares application components, permissions, and hardware requirements for the Android app.

## Logic
- **Permissions**: `CAMERA`, `INTERNET`.
- **Features**: `android.hardware.camera.ar` (required).
- **Activities**: `MainActivity` (launcher), `ArNavigationActivity` (portrait).
- **Metadata**: `com.google.ar.core` (required).

## Used By
- Android OS / Play Store.
