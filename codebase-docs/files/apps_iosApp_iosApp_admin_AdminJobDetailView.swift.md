## Purpose
Displays the full metadata and execution history for a single draft generation job. Acts as the intermediate step between job creation and draft review.

## Key Components
- **AdminJobDetailView**: A focused list view showing status, timestamps, and listed artifacts.
- **AdminJobDetailViewModel**: Manages the details of a single job and handles auto-polling if the job is still active.

## Logic Flow
1. **Fetch**: Loads the full job object from the backend.
2. **Poll**: If the status is `queued` or `processing`, the viewmodel automatically schedules a reload in 2 seconds.
3. **Transition**: If the status is `succeeded`, a "Review Draft" button appears, linking to `AdminDraftReviewView`.

## Technical Notes
- **Iconography**: Uses SF Symbols to provide instant visual feedback on job health (e.g., green checkmark for success, red x-mark for failure).
- **Artifact List**: Lists all files generated by the backend pipeline (e.g., `.svg`, `.json`), helping admins verify that all expected outputs exist before review.
